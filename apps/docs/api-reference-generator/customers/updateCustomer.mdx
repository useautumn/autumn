### Balance allocations

Set `billing_controls.balance_allocations` to reserve shared credits for entities. This customer-update-only control replaces the full configuration: include every feature and entity you want to keep, omit the field to leave it unchanged, or send `[]` to release all allocations.

```typescript TypeScript
await autumn.customers.update({
  customerId: "customer_123",
  billingControls: {
    balanceAllocations: [{
      featureId: "credits",
      interval: "month",
      allocations: [
        { entityId: "workspace_a", amount: 300 },
        { entityId: "workspace_b", amount: 200 },
      ],
    }],
  },
});
```

The response returns requested amounts under `billing_controls.balance_allocations`; read `balances` for effective amounts after proportional scaling.
