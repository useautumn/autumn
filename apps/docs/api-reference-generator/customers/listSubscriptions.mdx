Lists recurring plans, including add-ons. By default only `active` and `scheduled` plans are returned; pass `statuses: ["expired"]` to see plans a customer no longer has.

<Note>
  `past_due` is a filter, not a status. A past-due plan is returned with `status: "active"` and `past_due: true`.
</Note>

<Note>
  A page can hold fewer than `limit` rows (even zero) while `has_more` is `true`. Keep paginating until `has_more` is `false`.
</Note>
